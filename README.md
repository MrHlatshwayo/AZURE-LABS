# Azure Hands-On Labs (KodeKloud)
Practical lab exercises and infrastructure simulations completed on Microsoft Azure.

##  Key Focus Areas & Skills Practiced
* **Virtual Networking (VNets):** Configured and managed subnets, network security groups (NSGs), and resource routing.
* **Identity & Access Management:** Implemented Azure RBAC principles and managed resource scopes.
* **Resource Governance:** Practiced resource group provisioning, tagging, and cost-management tracking.
* **Storage & Compute:** Deployed and managed Azure virtual machines and storage accounts.
